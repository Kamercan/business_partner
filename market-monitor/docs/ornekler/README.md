# Örnek CSV şablonları

Bu dosyalar **boş şablondur** — içlerindeki sayılar sıfırdır ve gerçek fiyat
değildir. Amaçları, elle yönetilen serilerin beklediği sütun düzenini
göstermektir.

Kullanımı: dosyayı kendi verinizle doldurun, arayüzde **Veri girişi →
CSV yükle** adımında içeriği yapıştırın.

Zorunlu sütunlar `donem` ve `deger`; `kaynak` sütunu yoksa formdaki ortak
kaynak alanı kullanılır. Kaynak referansı olmayan satır **kabul edilmez** —
izi olmayan fiyat, karara temel olamaz.
